# Cabo Card Game

A multiplayer card game built with React, TypeScript, and Tailwind CSS.

## Features

- 4-player game with AI opponents
- Card animations with Framer Motion
- Special card abilities (peek, spy, swap)
- Score tracking across 10 rounds
- Round and game end modals

## Getting Started

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) to play.

## Game Rules

- Each player gets 4 cards (2 face-up, 2 face-down)
- Special cards (6-K) have unique abilities
- Lowest score after 10 rounds wins
- Call "Cabo!" when your hand is low to end the round early
